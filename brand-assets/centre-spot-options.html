The centre spot

The kickoff-circle mark — three treatments, large and small

A — Clean (no spot)

The primary mark. Survives every size. Avatar, favicon, watermark, comment threads.

B — Kickoff spot

One colour, one object — an espresso spot with a thin paper halo so it stays crisp over the green half. Reads as the kickoff spot, not a target. For large surfaces: packaging, hang tags, website hero.

C — Split spot

The one you feared — and you were right. The spot changes colour per half, so the eye reads concentric rings: a target, not a pitch. Shown only for comparison.

Left half solid — the first half, played · Right half open — the second half, yours to write
